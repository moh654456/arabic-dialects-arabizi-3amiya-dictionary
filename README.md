## English

Keyboards know standard Arabic, but not chat words like **عشان، هيك، شلونك، ازيك** or **3shan, ya3ni**. These files add them, plus iPhone-style Arabic and English layouts.

- **50,000** Arabic dialect words and **22,000** Arabizi words.
- No swear words. No insults in the Arabic list; the Arabizi list keeps 36 mild ones (like *zeft*).

### Pick your keyboard

| Keyboard | Arabic words | Arabizi words | iPhone layouts |
|---|:-:|:-:|:-:|
| [WM Keyboard](#wm-keyboard) | ✅ | ✅ | ✅ |
| [HeliBoard](#heliboard) | ✅ | ✅ | ✅ |
| [FUTO Keyboard](#futo-keyboard) | ✅ | ❌ | ✅ |
| [Gboard](#gboard) | ✅ | ✅ | ❌ |
| SwiftKey | ❌ | ❌ | ❌ |

SwiftKey can't import word lists or layouts. Gboard can't import layouts.

**To download a file:** long-press its link and tap **Download link**.

### WM Keyboard

Files: [arabic_dialects.txt](arabic_dialects.txt?raw=true) · [arabizi_dialects.txt](arabizi_dialects.txt?raw=true) · [arabic_ios.wmlayout.json](arabic_ios.wmlayout.json?raw=true) · [english_ios.wmlayout.json](english_ios.wmlayout.json?raw=true)

- **Words:** **Typing → Suggestions → Custom dictionaries → Arabic → Import word list** → pick `arabic_dialects.txt`. No Arabic box? Tap **Add a word list for another language** first.
- **Arabizi:** add the **Arabizi** language in **Languages & layouts**, then import `arabizi_dialects.txt` under **Arabizi**.
- **Layouts:** **Layout & size → Key layouts → Import a layout** → pick the file → **Import and turn on**.

### HeliBoard

Files: [heliboard_arabic_dialects.dict](heliboard_arabic_dialects.dict?raw=true) · [heliboard_arabizi.dict](heliboard_arabizi.dict?raw=true) · [heliboard_arabic_ios.txt](heliboard_arabic_ios.txt?raw=true) · [heliboard_english_ios.txt](heliboard_english_ios.txt?raw=true)

- **Words:** **Dictionaries → ➕** → pick `heliboard_arabic_dialects.dict` → language **Arabic** → **OK**. It is added next to HeliBoard's own Arabic dictionary.
- **Arabizi:** same, with `heliboard_arabizi.dict` and language **English**.
- **Layouts:** **Languages & Layouts → Arabic → Layout ➕ → Load file** → pick `heliboard_arabic_ios.txt` → **Save**. For English, do the same under **English** with `heliboard_english_ios.txt`.
- HeliBoard keeps its own Shift, comma and period keys.

### FUTO Keyboard

Files: [futo_arabic.dict](futo_arabic.dict?raw=true) · [futo_arabic_ios.yaml](futo_arabic_ios.yaml?raw=true) · [futo_english_ios.yaml](futo_english_ios.yaml?raw=true)

- **Words:** open `futo_arabic.dict` from your **Files** app → **FUTO Keyboard** → language **Arabic** → **Import**. It replaces FUTO's Arabic dictionary and already includes standard Arabic.
- **Layouts:** **Help & Feedback** → tap the version number 8 times → go back → **Developer Settings → Custom layouts → Create new layout**. Type `ar` in **Language**, replace the **Layout YAML** text with the text of `futo_arabic_ios.yaml`, then **Save**. For English, use `en` and `futo_english_ios.yaml`.
- To switch layouts, long-press the space bar.
- No Arabizi: FUTO allows only one dictionary per language.

### Gboard

Files: [gboard_arabic_dialects.zip](gboard_arabic_dialects.zip?raw=true) (top 10,000 words) · [gboard_arabizi.zip](gboard_arabizi.zip?raw=true) (top 5,000 words)

- **Dictionary → Personal dictionary → All languages → ⋮ → Import** → pick the zip file.
- The screen may freeze for a minute or two. The lists are shorter because Gboard imports slowly.

### Red lines under words?

They come from Android's spell checker, not the keyboard. In your phone's **Settings**, search for **Spell checker**, then choose your keyboard or turn it off.

## العربية

تعرف لوحات المفاتيح العربيةَ الفصحى، لكنها لا تعرف الكلمات العامية مثل **عشان، هيك، شلونك، ازيك**، ولا كلمات العربيزي مثل **3shan** و**ya3ni**. تضيف هذه الملفات تلك الكلمات، وتوفّر أيضًا تخطيطين عربيًّا وإنجليزيًّا على غرار لوحة مفاتيح الآيفون.

- **50,000** كلمة عامية بالحروف العربية، و**22,000** كلمة بالعربيزي.
- لا تحتوي القائمتان على ألفاظ نابية، والقائمة العربية خالية من الشتائم أيضًا، أما قائمة العربيزي ففيها 36 شتيمة خفيفة (مثل *zeft*).

|---|:-:|:-:|:-:|
| [WM Keyboard](#ar-wm) | ✅ | ✅ | ✅ |
| [HeliBoard](#ar-heli) | ✅ | ✅ | ✅ |

<a name="ar-wm"></a>

### ‏WM Keyboard

الملفات: [arabic_dialects.txt](arabic_dialects.txt?raw=true) · [arabizi_dialects.txt](arabizi_dialects.txt?raw=true) · [arabic_ios.wmlayout.json](arabic_ios.wmlayout.json?raw=true) · [english_ios.wmlayout.json](english_ios.wmlayout.json?raw=true)

- **الكلمات:** **الكتابة ← الاقتراحات ← القواميس المخصصة ← العربية ← استيراد قائمة الكلمات**، ثم اختر الملف `arabic_dialects.txt`. إذا لم تجد العربية في القائمة، فاضغط أولًا على **إضافة قائمة كلمات للغة أخرى**.
- **العربيزي:** أضف لغة **Arabizi** من **اللغات**، ثم استورد الملف `arabizi_dialects.txt` ضمن **Arabizi**.
- **التخطيطات:** **التخطيط والحجم ← تخطيطات المفاتيح ← استيراد تخطيط**، ثم اختر الملف، ثم اضغط على **استيراد وتفعيل**.

<a name="ar-heli"></a>

### ‏HeliBoard

الملفات: [heliboard_arabic_dialects.dict](heliboard_arabic_dialects.dict?raw=true) · [heliboard_arabizi.dict](heliboard_arabizi.dict?raw=true) · [heliboard_arabic_ios.txt](heliboard_arabic_ios.txt?raw=true) · [heliboard_english_ios.txt](heliboard_english_ios.txt?raw=true)

- **الكلمات:** **القواميس ← ➕**، ثم اختر الملف `heliboard_arabic_dialects.dict`، واختر اللغة **العربية**، ثم اضغط على **حسنًا** (OK). يُضاف هذا القاموس إلى جانب قاموس HeliBoard العربي.
- **العربيزي:** كرّر الخطوات نفسها مع الملف `heliboard_arabizi.dict` واللغة **English**.
- **التخطيطات:** **اللغات والتخطيطات ← العربية ← التخطيط ➕ ← تحميل ملف**، ثم اختر الملف `heliboard_arabic_ios.txt`، ثم اضغط على **حفظ**. وللإنجليزية كرّر الخطوات نفسها ضمن **English** مع الملف `heliboard_english_ios.txt`.
- يحتفظ HeliBoard بمفاتيح Shift والفاصلة والنقطة الخاصة به.

<a name="ar-futo"></a>

### ‏FUTO Keyboard

الملفات: [futo_arabic.dict](futo_arabic.dict?raw=true) · [futo_arabic_ios.yaml](futo_arabic_ios.yaml?raw=true) · [futo_english_ios.yaml](futo_english_ios.yaml?raw=true)

- **الكلمات:** افتح الملف `futo_arabic.dict` من تطبيق **الملفات**، واختر **FUTO Keyboard**، ثم اللغة **العربية**، ثم **Import**. يحلّ هذا الملف محلّ قاموس FUTO العربي، ويتضمّن كلمات الفصحى أيضًا.
- **التخطيطات:** افتح **Help & Feedback**، ثم اضغط على رقم الإصدار 8 مرات، ثم ارجع وافتح **Developer Settings → Custom layouts → Create new layout**. اكتب `ar` في خانة **Language**، والصق نص الملف `futo_arabic_ios.yaml` مكان نص خانة **Layout YAML**، ثم اضغط على **Save**. وللإنجليزية اكتب `en` واستخدم الملف `futo_english_ios.yaml`.
- للتبديل بين التخطيطات، اضغط مطوّلًا على مفتاح المسافة.
- لا يدعم FUTO العربيزي، لأنه لا يقبل إلا قاموسًا واحدًا لكل لغة.

<a name="ar-gboard"></a>

### ‏Gboard

الملفات: [gboard_arabic_dialects.zip](gboard_arabic_dialects.zip?raw=true) (أكثر 10,000 كلمة شيوعًا) · [gboard_arabizi.zip](gboard_arabizi.zip?raw=true) (أكثر 5,000 كلمة شيوعًا)

- **القاموس ← القاموس الشخصي ← جميع اللغات ← ⋮ ← استيراد** (Dictionary → Personal dictionary → All languages → ⋮ → Import)، ثم اختر ملف zip.
- قد تتجمّد الشاشة دقيقة أو دقيقتين. القائمتان أقصر من القوائم الكاملة لأن Gboard بطيء في الاستيراد.

### خطوط حمراء تحت الكلمات؟

مصدرها المدقق الإملائي في أندرويد، لا لوحة المفاتيح. افتح **الإعدادات** في هاتفك، وابحث عن **المدقق الإملائي**، ثم اختر لوحة مفاتيحك أو أوقف تشغيله.
